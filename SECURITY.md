# Security policy

This is an early demonstration release. Use the latest tagged release and a supported, patched Shopware version. No independent security certification is claimed.

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/Math1987/agentenblick/security/advisories/new). If that form is unavailable, open an issue asking for a private contact without including the vulnerability, credentials, exploit payloads or merchant data. Do not put secrets or personal traffic in public issues.

Include the affected commit/version, Shopware and PHP versions, expected and observed behavior, and a minimal reproduction using a disposable shop and synthetic data. Reports concerning data minimization, signature verification, trusted proxies, SSRF, access control or benchmark anonymity are especially relevant. A response or remediation deadline is not guaranteed.

The private benchmark service is separately deployed. Never publish its credentials or a merchant installation secret. An identity classification is evidence about the request, not authorization to make purchases or a statement about a customer's mandate.
