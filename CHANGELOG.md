# Changelog

## 0.1.2 — experimental voluntary disclosure

- Add an opt-in native WebMCP introduction and an accessible first-party form, with no automatic declaration or additional cookie.
- Accept only a service and coarse task category; attach unverified declarations to the existing native Shopware session without adding a second session or a fake navigation request.
- Preserve stronger identity evidence and pre-declaration minimization; keep browser support and spontaneous participation distinct from technical contract tests.
- Production performance qualification and Shopware Store submission remain pending.

## 0.1.1 — isolated demonstration

- Route benchmark traffic to separate fixed production and demonstration services using the persisted identity mode.
- Block legacy demonstration credentials until an explicit migration, preserving local reporting and opt-out.
- Show the matching dashboard link and migration instructions in English and German.
- Production performance qualification remains pending; this is a demonstration prerelease.

## 0.1.0 — demonstration

- Server-side request measurement and CLI reports, trusted-proxy diagnostics and minimized storage.
- Separate signature, published IP range, reverse-DNS and declared identity evidence.
- Native administration overview, agents, CSV, independently observed journey steps and known failures.
- Optional consent-based benchmark with frozen aggregate payloads, withdrawal and publication thresholds.
- Experimental undeclared-automation score, disabled by default. Frozen evaluation detected 11 of 13 scripted profiles; human false-positive calibration is unavailable.
- Explicit Health probes of configured public HTTPS domains, bounded robots rules, observed contradictions, discovery endpoint statuses and optional server-origin user-agent tests.
- Shopware 6.6/6.7 administration components, public PHP/static-analysis/administration CI and German/English operational and privacy documentation.
- Reduced persistence work with fresh primary daily-key reads, atomic proxy counters and combined locked session updates; closed-session contribution corrections remain idempotent.

Health diagnostics and release compatibility checks are recorded in the acceptance reports, including measured limits. The post-response performance target remains a production qualification gate. Shopware Store submission is deferred; this is a demonstration release.
